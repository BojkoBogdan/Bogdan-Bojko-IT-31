# Самостійна робота: огляд і графік

!!! info "Матеріали в підготовці"
    Ця сторінка — заготовка. Розгорнуті методичні вказівки до кожної
    самостійної роботи з'являться тут пізніше.

Загальний обсяг самостійної роботи з дисципліни — **67 годин**
(23 позиції, прив'язані до конкретних занять). Нижче — повний графік,
розподілений за модулями; докладніше кожен модуль — на власній сторінці.
